# 在 Browse 中删除目录

管理员可以删除 Maven、npm、PyPI、NuGet、Helm、Yum、RubyGems 和 Raw hosted
仓库中的目录内容。打开目录后点击 **Delete**，查看仓库、完整目录路径、组件和文件
数量以及全部受影响路径，然后输入完全相同的目录路径，才能确认删除。
点击取消或按 Escape 关闭预览，不会修改仓库。

该操作要求现有 Browse 删除权限（`nexus:*`）。仓库根目录、proxy/group 仓库及其他
格式不提供此批量操作，原有单组件和单文件操作继续保留。删除不可撤销，此功能不提供回收站
或恢复能力；实际存储空间由现有的引用感知垃圾回收流程另行释放。

单次预览最多包含 500 个文件和 1,000 个目录树节点。超出限制时不会删除任何内容，
需要选择更小的目录；服务端不会执行被截断的预览。对于按包删除的格式，需要选择
包含完整包的目录，不能因选中了部分文件而静默删除目录外的关联文件。生成的元数据
在预览中单独标注，由协议维护，删除后可能保留或重新生成。

如果执行前目录内容变化，服务端会拒绝删除，要求重新预览。预览与执行可以由不同
副本处理，通过数据库锁和一个事务保护已确认的制品身份；最终校验后提交的新上传
会保留。事务失败会一起回滚删除和元数据重建标记。管理审计日志记录操作者、仓库、
目录、执行结果及删除文件数。下载和索引更新遵循原有协议流程：其他副本按版本水位
轮询间隔（默认两秒）感知下载缓存失效，部分协议索引仍在后台重建。

删除后保留仍存在目录的展开状态和树内滚动位置；只有剩余内容不足原高度时才会限制
滚动范围。如果原选中项被删除，则选中最近仍存在的父目录。
