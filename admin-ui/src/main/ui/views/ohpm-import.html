OHPM Import

Plan, verify and resume package imports into an OHPM hosted repository

Dry run verifies archives and saves a plan without writing target packages. To resume a directory import, select the same directory again. An optional matching .metadata.json file preserves package metadata and tags; without it, versions are imported without tags.

Existing versions and conflicting tags are never overwritten. Users, tokens, permissions and storage settings require separate configuration. Registry imports use the selected proxy's remote credentials and download allowlist.
